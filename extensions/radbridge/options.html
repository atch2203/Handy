RadBridge options

RadBridge inserts text you dictate in Handy into a field of a web page, without moving keyboard focus. In Handy, set Paste Method to Send to Browser Extension.

Connection to Handy

Copy the token from Handy: Settings → Advanced → Paste Method.

Pages

A Chrome match pattern. Saving asks Chrome for access to these pages only. For the test page use http://localhost/*.

Chrome's Memory Saver unloads background tabs, and RadBridge can't insert into an unloaded tab. Add the site to Always keep these sites active in chrome://settings/performance (Edge: edge://settings/system, Never put these sites to sleep).
